# Golden Path Specification

## Promise

Turn fragmented information into a structured, editable workflow and a reviewable handoff. Generation organizes user-authored workspace content; it does not fact-check or certify that content.

## Journey

1. **Choose a primary template, guided demo, or blank workspace.**
2. **Paste source material** into the source panel.
3. **Apply or split the source** into canvas nodes, preserving the workspace if the user cancels an overwrite confirmation.
4. **Organize and review** the nodes, connections, required categories, and review decisions.
5. **Validate the output path.** A required review must contribute to the path reaching an output; unrelated review nodes do not satisfy it.
6. **Generate and inspect** the template-structured deliverable. Required sections must have matching content before readiness is reported.
7. **Export and recover.** Markdown is the complete editable text handoff; Project JSON is the recoverable workspace handoff. PDF is a simplified reading view.
8. **Save and reopen** from browser-local workspaces, snapshots, or validated imports.

The in-app Docs page explains the operator workflow. Automated journey coverage is listed in the [test strategy](TEST-STRATEGY.md); participant task-completion and time-saved results remain unmeasured in the [study protocol](../research/STUDY_PROTOCOL.md).
